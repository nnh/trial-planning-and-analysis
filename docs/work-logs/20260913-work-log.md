## 決定事項

- 工程の採番を区間0から始める形をやめ、区間1から区間5へ繰り上げた。0番は「本番の前」と読まれ、n番目と番号がずれる。採番の規則は作業規約へ切り出し、全プロジェクトへ適用する
- 章番号を振る文書と振らない文書の切り分けを決めた。軸は「その文書の節を文書の外から名指しする必要があるか」。手順書・規程・仕様書は振り、生きた文書・README・記録は振らない
- 判断票は別の台帳を作らず、決定の台帳の区分「未決」として持つ。状態・仮採用案・影響工程を同じ行に置く
- 固定後に統計解析計画書と異なる扱いを採ることを、承認・根拠・報告先の3つを持つことを条件に認める。正本の階層が禁じるのは、下位文書が正本を自称して上位を黙って上書きすることに限る
- 変数の属性の正本を層で分ける。SDTM は受領 define.xml と実データ、ADaM は変数マップ
- 群の表示名の正本を表示文言のカタログに一本化する
