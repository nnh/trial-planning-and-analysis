# 通過記録

作成日：2026-08-22
改訂日：2026-08-22

試験を1本通したら、ここへ1件の通過記録を残す。まだ登録は無い。

## 書くもの

- 試験名（匿名化する場合はその方針も明記）
- 領域・規模（例数の桁）
- 使った枠組みの版（日付で指す。版番号は付けない）
- 工程ごとに機械検査が拾った件数
- 新しく足した規則
- 人の判断で止まった回数（必須2点・条件付き3点の内訳）

## 目的

通過記録が無いと規則の効き目が測れず、規則を落とす判断もできない。止まった回数を試験ごとに並べることが、枠組みが効いているかどうかの唯一の証拠になる。

## ファイル名

`<試験名または匿名ラベル>-<YYYYMMDD>.md` とする。
